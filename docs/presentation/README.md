# Presentation

The CityTour pitch deck for HackYeah 2026 (Huawei challenge).

- [`CityTour-keynote.pdf`](CityTour-keynote.pdf): the 25 slides, 1920×1080.
- [`speaker-notes.md`](speaker-notes.md): what to say on each slide.
- [`CityTour-pitch-5min.pdf`](CityTour-pitch-5min.pdf) + [`pitch-5min.md`](pitch-5min.md): the **5-minute final pitch** (8 slides from the keynote, demo included, timed script).

Every phone and watch screen in the deck is a real screenshot from the DevEco emulators (`docs/img/`). Tour cover photos: Jakub Hałun, Chris Olszewski and Marco Almbauer, Wikimedia Commons, CC BY-SA 4.0. Map data © OpenStreetMap contributors.
